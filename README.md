# 🧮 Калькулятор на Python

## Описание проекта

**Калькулятор** — это простая программа на языке Python, которая выполняет базовые арифметические операции: сложение, вычитание, умножение и деление.

> *Проект создан в рамках практической работы ПР12 по МДК.02.02.*

### Возможности программы

- ✅ сложение двух чисел;
- ✅ вычитание;
- ✅ умножение;
- ✅ деление (с проверкой деления на ноль);
- ~~поддержка дробей~~ (в планах).

## Установка и запуск

### Что нужно установить

1. **Python** версии 3.10 или выше — [скачать здесь](https://www.python.org/downloads/).
2. Любой редактор кода (например, **VS Code**).

### Как запустить

1. Скопируйте файл `calculator.py` из репозитория.
2. Откройте терминал в папке с файлом.
3. Выполните команду:

   ```bash
   python calculator.py
